# Edgekin

**让当前网页的边缘，变成一场小冒险。**

A lightweight platform game built from the visible geometry of the current web page.

Edgekin 将网页中可见的卡片、按钮、输入框、图片和图标转换为有碰撞的地形。控制一个黑色小人沿轮廓跑跳、蹲行和借墙反跳，连续收集随机刷新的硬币；长平台上可出现需要躲避的巡逻红球。既可通过 Chrome / Edge 扩展在普通网页上启用，也可作为 JavaScript 模块接入自己的应用。

当前版本：**0.3.3** · [版本记录](CHANGELOG.md) · [MIT 许可证](LICENSE)

## 特点

- **地图来自当前网页**：读取当前可见区域的 DOM 几何与 CSS 样式，不依赖预设关卡。
- **以封闭轮廓为主**：识别矩形、圆角矩形、圆形、椭圆及 CSS / SVG 凸多边形；清理重复内圈、合并组合控件，为嵌套大外框开出入口。加粗边界配白色衬边，便于辨认照片上的地形。
- **动作与选关共用物理规则**：路线模拟普通跳跃、墙跳、步行和蹲行，允许竖向与折返路线。
- **连续探索**：按屏幕区域轮换刷新硬币，优先近期未去过的边角和较有挑战的位置，验证抵达与返回通路。每枚 +1、失败重生 −1，最低 0 分；右上角显示积分条与加减分动画。巡逻障碍只放在有足够跳跃空间的长平台上。
- **轻量运行**：原生 DOM API + Canvas 2D，无运行时第三方依赖和游戏引擎；固定步长物理与 `requestAnimationFrame` 绘制。
- **按需工作**：生成时分批扫描与规划；暂停时停止动画，静止页面不持续扫描。
- **适应页面更新**：收集模式在后台更新地图，迁移人物、有效金币和返回点，保留分数与游戏时钟。收币后寻找下一目标时仍可移动。
- **在本地处理页面**：游戏代码不上传页面内容，不发送分析数据；扩展只申请 `activeTab` 和 `scripting` 权限。

## 快速开始

需要 **Node.js 22 或更高版本**，以及随 Node.js 安装的 npm。

```sh
git clone https://github.com/suyoutzy/Edgekin.git
cd Edgekin
npm ci
npm run build
```

### 在 Chrome / Edge 中使用

1. 打开 Chrome 的 `chrome://extensions` 或 Edge 的 `edge://extensions`。
2. 开启「开发者模式」，点击「加载已解压的扩展程序」，选择项目中的 **`extension/` 文件夹**。
3. 打开普通 `http://` 或 `https://` 网页，点击浏览器工具栏中的 Edgekin 图标，再点击页面右上角的「开始」。
4. 再次点击扩展图标，可从当前网页移除游戏。

`extension/content.js` 由构建生成，首次加载扩展前必须完成 `npm run build`。修改源码后重新构建，在扩展管理页重新加载 Edgekin，并刷新目标网页。

浏览器内置页面、扩展商店等受保护页面无法注入，扩展图标会显示 `!`。本地 `file://` 页面需要在扩展详情中允许访问文件网址。

### 运行演示页

```sh
npm run serve
```

打开 [http://127.0.0.1:4173](http://127.0.0.1:4173)。演示页提供方便验证的页面元素，扩展仍可在其他普通网页上识别地图。

## 操作

| 操作 | 效果 |
| --- | --- |
| ← / → | 左右移动 |
| ↑ | 跳跃；空中贴墙时松开后再按，可向外反跳 |
| ↓ | 地面下蹲，水平速度减半、无法跳跃；空中快速下落 |
| 点击「暂停」 | 暂停；面板提供「继续」「重新计分」「换一关」 |
| 暂停后点击「换一关」 | 重新生成地图，保留分数继续探索 |

头顶空间不足时，松开 ↓ 仍会保持蹲姿；离开低处后自动站起。跳跃支持 100ms 的按键缓冲，离边宽限为 20ms（60Hz 下约一个后续物理步），长按 ↑ 不会连续触发。

默认是连续收集模式：收集硬币后刷新下一枚，绿色旗标标记最近收集位置。掉出视口或触碰红球会回到该返回点，扣 1 分（最低 0），并获得约 0.9 秒的碰撞保护。暂停时红球、临时平台与游戏时间一起停止。空中按 ↓ 会立即结束上升、加速下降，落地后按住 ↓ 则转为下蹲。

换关、滚动和页面布局更新保留当前实例的分数；「重新计分」回原起点并清零。移除扩展或按 F5 刷新整个网页会结束这次计分，不保存长期成绩。

输入框获得焦点或窗口失焦时自动暂停。收集模式在页面内部更新、滚动或调整窗口尺寸后，分批扫描并迁移游戏状态；普通变化期间沿用旧地图继续玩，落脚面被移除时安全搬移且不扣分。整片地形暂时消失时会等待新落脚面并自动继续，手动暂停与输入焦点优先。画布不拦截鼠标，游戏控件区域仍可点击。

原起点到终点玩法保留为 `mode: 'course'`：掉落回原起点，通关停止，长按 ↓ 或点击按钮重开；页面几何变化后重新生成并暂停。

## 地图如何生成

1. 扫描当前可见页面，提取可见元素的几何边界。
2. 过滤、去重和归并轮廓，清理无法进入的紧凑内圈，为嵌套外框寻找入口。
3. 构建碰撞边界和落脚面，使用实际人物物理模拟可达连接。
4. 从有效候选中随机选择具有足够间距和出生净空的起终点，避开近期重复组合。

连续收集把常见桌面视口分为 3×2 个区域，较小视口用 2×2。拥有几何合格落脚点的区域进入随机洗牌袋，尽量每轮各访问一次，避免相邻目标反复留在同一区域；具体落点偏向边角和较有挑战的位置，距离不加分。先补采遗漏的动作源、修补少量跨区连接，再从实际人物位置重放验证。选点期间继续运行物理，并预备下一枚金币；没有合格目标时可继续移动，换落脚处再尝试。

轮廓的侧边和底边同样阻挡人物，不能从下方穿过。收集模式优先增加有双向通路的跨区连接，每处最多三段；辅助平台总量在宽视口中最多 6 个、其他视口最多 4 个，剩余预算用于局部挑战。其中最多一条非主通路平台为琥珀色：实际触碰或踩到后变红预警约 0.3 秒，消失 3 秒后重现；身体占据其位置时延后恢复。隐藏时仅留虚线提示、不碰撞。硬币、返回点和必要连接使用永久地形。

较大的空容器可打开入口以利用内部空间，图片、背景图和输入控件不按空容器处理。补充地形不随每枚硬币重建。地形不足时在辅助平台总预算内最多尝试一条备用落脚线；无法找到合格路线则提示无法生成。

游戏面板不显示复杂度。`getMapStats()` 仍保留轮廓覆盖统计，表示**已标出的有效轮廓数 / 当前页面符合规则的全部有效轮廓数**，不是关卡难度；补充地形单独计数。详细规则、预算与算法边界见 [地图生成说明](docs/map-generation.md)。

## 作为 JavaScript 模块接入

构建后将 `dist/` 作为静态资源提供，通过 ES Module 导入：

```js
import { mountEdgekin } from './dist/index.js';

const game = mountEdgekin({
  root: document.body,
  mode: 'collect',
  onCollect: score => console.log('Score:', score),
});

await game.start();
```

实例提供 `start()`、`pause()`、`restart()`、`regenerate()`、`getMapStats()`、`getSessionStats()` 和 `destroy()`。`start()` 与 `regenerate()` 是异步方法。游戏界面位于独立 Shadow DOM 中，减少宿主样式干扰。

API 行为与清理示例见 [模块接入说明](docs/api.md)。这是源码项目，目前未发布 npm 包或浏览器商店版本。

## 当前限制

- 面向桌面浏览器；视口小于 640×480 时不生成关卡。桌面覆盖层、手机和嵌入式设备暂未实现。
- 识别 DOM / CSS 边界，不截屏，不解析图片像素或任意 SVG path；显式多边形支持 3–16 个顶点的凸形状，其他路径使用元素边界。不扫描 iframe 内部或页面组件的 Shadow DOM。
- 路线搜索有采样和计算预算，不穷举所有可能操作；部分页面可能无法生成，或产生较简单的路线。
- 区域轮换不保证每块地形都已连通。未验证区域继续计入诊断覆盖分母，当前批次不能抵达或返回的区域会延后；大断点不一定能在有限平台预算内修复。
- 页面更新目前采用分批完整扫描与几何差异复用，尚未实现只扫描脏区域；复杂页面仍可能有计算等待。页面内部更新可迁移状态，整页刷新后不恢复本次会话。
- 高频布局变化、极大页面和不同设备的帧率需要实际测量。60 FPS 是目标，并非对任意网页的性能保证。
- 巡逻障碍最多两个，不适合的页面不会添加；首次目标无法通过带障碍验证时会撤去障碍。目标搜索有预算，不保证任意页面能无限刷新。
- 摇摆障碍、移动平台、商店和长期成绩存储尚未实现。
